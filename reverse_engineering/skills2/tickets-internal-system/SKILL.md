# tickets-internal-system

## Overview

This skill explains how to access internal tickets and view status

## Instructions

### 1. Fetch the internal tickets system file

Load file tickets.txt which is under current project folder

This provides a list of internal tickets with its status separated by semicollon. Examples: 
1234: InProgress
987: Completed

### 2. Answer questions about tickets

Based on the question, identify the ticket in the tickets.txt file and return status to the user or answer any question related.
